1

한 줄 요약

층을 $L$ 개 쌓으면 backward 에서 Jacobian이 $L$ 번 곱해져 gradient 가 지수적으로 죽거나 터진다. 그리고 최적화가 도착한 최소점의 모양(sharp 인가 flat 인가)이 일반화를 좌우하는데, 그 모양은 batch 크기와 learning rate 가 정한다.

학습 목표

  1. $\prod_\ell \mathbf{J}_\ell$ 의 spectral radius 로 vanishing·exploding gradient 를 설명할 수 있다.
  2. gradient clipping 이 크기만 줄이고 방향은 보존한다는 것을 식으로 보일 수 있다.
  3. batch 크기와 최소점의 sharpness·일반화의 관계를 설명하고, 그 주장의 한계도 말할 수 있다.
2

직관

전화 게임을 생각한다. 한 사람이 다음 사람에게 말을 전하는데, 매번 0.25배로 작게 속삭인다면 10명을 지나면 백만분의 1 크기가 되어 아무것도 안 들린다. 반대로 매번 1.5배로 크게 외치면 50명 뒤에는 귀가 찢어진다.

backpropagation 이 정확히 이 구조다 — 3.4에서 본 Jacobian 곱 $\mathbf{J}_L\cdots\mathbf{J}_1$ 이 곧 "매 단계 몇 배"이고, 층 수만큼 거듭제곱된다. 2.7의 반복 선형변환과 같은 문제이며, spectral radius $\rho$ 가 1 에서 조금만 벗어나도 결과가 극단으로 간다.

핵심

깊은 신경망 학습의 어려움은 최적화 알고리즘의 문제가 아니라 신호 전달의 문제다. gradient 가 죽으면 어떤 optimizer 도 방향을 알 수 없다. 그래서 해법이 optimizer 가 아니라 구조(residual)·정규화(BatchNorm·LayerNorm)· 초기화·clipping 쪽에서 나왔다.

3

형식적 정의

Vanishing & Exploding Gradient 기울기 소실과 폭주

$$ \frac{\partial\mathcal{L}}{\partial\mathbf{h}_0} = \frac{\partial\mathcal{L}}{\partial\mathbf{h}_L}\prod_{\ell=1}^{L}\mathbf{J}_\ell, \qquad \left\|\prod_\ell \mathbf{J}_\ell\right\| \sim \rho^{L} $$
(1)

$\rho<1$ 이면 gradient 가 지수적으로 사라지고(vanishing), $\rho>1$ 이면 지수적으로 터진다(exploding). 중간이 없다 — $\rho^L$ 은 $L$ 이 커질 때 0 이나 $\infty$ 로만 간다.

원인$\rho$ 에 미치는 영향대책
sigmoid·tanh 포화$\phi'\leq0.25$ 로 $\rho$ 를 끌어내린다ReLU 계열 (3.2)
weight 초기화가 작음$\|\mathbf{W}\|$ 가 작아 $\rho<1$Xavier·He 초기화
weight 초기화가 큼$\rho>1$같음 + clipping
RNN 의 시간축 반복같은 $\mathbf{W}$ 가 $T$ 번 곱해진다LSTM·GRU 의 게이트, clipping
층이 깊다$L$ 자체가 지수의 밑수residual connection

가장 강력한 해법이 residual 이다. 3.4 유도 3 에서 본 대로 $\mathbf{y}=\mathbf{x}+F(\mathbf{x})$ 의 Jacobian은 $\mathbf{I}+\mathbf{J}_F$ 이고, 곱을 전개하면 아무것도 곱해지지 않은 $\mathbf{I}$ 항이 살아남아 gradient 가 손상 없이 첫 층까지 도달한다. 이것이 100층 이상의 network 가 학습 가능해진 결정적 이유다.

쉬운 말로

복사기로 복사본을 복사하고, 그 복사본을 또 복사하는 일을 100번 반복한다고 생각해 보세요. 매번 조금씩 흐려지면 마지막에는 백지가 됩니다.

residual connection 은 원본을 옆에 끼워 함께 전달하는 것입니다. 복사가 아무리 흐려져도 원본이 함께 오니 정보가 살아남습니다. 그래서 층을 아무리 쌓아도 첫 층까지 신호가 닿습니다.

Gradient Clipping

$$ \hat{\mathbf{g}} = \begin{cases} \mathbf{g} & \|\mathbf{g}\|\leq c\\[4pt] \dfrac{c}{\|\mathbf{g}\|}\,\mathbf{g} & \|\mathbf{g}\|>c \end{cases} \qquad\Longleftrightarrow\qquad \hat{\mathbf{g}} = \min\!\left(1,\frac{c}{\|\mathbf{g}\|}\right)\mathbf{g} $$
(2)

gradient 의 크기만 잘라 내고 방향은 그대로 둔다 — 전체에 같은 양수를 곱하기 때문이다(유도 2). exploding gradient 를 막는 가장 값싸고 확실한 방법이며, RNN 과 Transformer 학습에서 사실상 기본 설정이다1.

norm clipping (권장)value clipping
기준전체 gradient 의 노름 $\|\mathbf{g}\|$각 원소 $g_i$ 를 개별적으로
방향보존된다바뀐다 (큰 성분만 눌린다)
APIclip_grad_norm_(params, c)clip_grad_value_(params, v)
전형적 값$c=1.0$ (LLM 학습에서 표준)드물게 사용

중요한 실무 세부 하나. norm 은 모든 파라미터를 하나로 이어 붙인 전체 노름이어야 한다. 층마다 따로 자르면 층 간 gradient 비율이 바뀌어 방향이 달라진다. 그리고 clipping 은 gradient accumulation 을 전부 마친 뒤, optimizer step 직전에 한 번만 적용한다.

Sharp vs Flat Minimum 뾰족한 최소와 평평한 최소

같은 training loss 값을 갖는 최소점이라도 주변이 얼마나 가파른가가 다르다. Hessian의 eigenvalue 크기가 그 척도다.

Sharp MinimumFlat Minimum
Hessian eigenvalue크다작다
조금 벗어나면loss 가 급격히 오른다loss 가 거의 안 변한다
train↔test 분포 차이에취약강건
어떤 학습이 도달하나큰 batch, 작은 $\eta$작은 batch, 큰 $\eta$

직관은 이렇다 — test loss 곡면은 train loss 곡면을 조금 옆으로 밀어 놓은 것과 비슷하다. sharp minimum 에서는 조금만 밀려도 loss 가 크게 오르지만, flat 에서는 거의 그대로다. Keskar 등의 실험이 이 그림과 함께 큰 batch 로 학습하면 sharp minimum 에 도달해 일반화 갭이 생긴다는 것을 보고했다2.

이 이야기에는 반론이 있다

Dinh 등은 ReLU network 를 재매개변수화하면 함수는 그대로인 채 sharpness 를 마음대로 키우거나 줄일 수 있다는 것을 보였다3. 한 층에 $c$ 를 곱하고 다음 층을 $1/c$ 로 나누면 같은 함수인데 Hessian eigenvalue 는 바뀐다 (3.5의 scale 대칭).

따라서 "flat 하면 일반화가 좋다"는 무조건적 법칙이 아니다. sharpness 를 재려면 스케일에 불변인 척도를 써야 하고, 그런 척도로 재면 상관관계가 유지된다는 후속 연구도 있다. 실무 지침으로는 유용하지만 정리(theorem)로 인용해서는 안 된다.

Batch Size

3.6에서 batch 크기가 gradient 잡음을 $\sigma/\sqrt{B}$ 로 정한다고 보았다. 그 잡음이 어떤 최소점에 도달하는가까지 바꾼다는 것이 이 절의 추가 논점이다.

$$ \text{잡음 세기} \ \sim\ \frac{\eta}{B} \qquad (\text{SGD 를 확산 과정으로 볼 때의 온도}) $$
(3)

$\eta/B$ 가 "온도"처럼 작동한다 — 높으면 좁은 골에서 튀어나와 넓은 골을 찾고, 낮으면 가장 가까운 골에 그대로 앉는다. 그래서 $B$ 를 키울 때 $\eta$ 를 함께 키우는 linear scaling rule 이 sharpness 관점에서도 말이 된다.

$B$ 를 키우면일어나는 일대책
스텝 수가 준다같은 epoch 에 갱신이 적다$\eta$ 를 비례해 키운다
잡음이 준다sharp minimum 에 앉기 쉽다$\eta$ 상향 + warmup
초반이 불안정큰 $\eta$ 로 발산warmup (3.8)
critical batch size 초과더 키워도 학습이 빨라지지 않는다GPU 를 다른 데 쓴다

마지막 줄이 실무에서 중요하다. warmup + linear scaling 을 제대로 적용하면 $B=8192$ 로도 정확도 손실 없이 ImageNet 을 학습할 수 있다4 — "큰 batch 는 나쁘다"가 아니라 "큰 batch 에는 맞는 $\eta$ 와 warmup 이 필요하다"가 정확한 진술이다. 다만 어느 지점을 넘으면 batch 를 키워도 스텝 수가 그만큼 안 줄어드는 한계(critical batch size)가 있다.

Optimization and Generalization 최적화와 일반화

둘은 다른 문제다 — 최적화는 training loss 를 낮추는 것, 일반화는 본 적 없는 data 에서 잘하는 것이다. 딥러닝에서는 전자가 거의 항상 성공하므로, 실질적인 질문은 언제나 후자다.

관찰의미
무작위 label 도 train error 0 으로 맞춘다표현력만으로는 일반화를 설명 못 한다 (3.9)
파라미터가 data 보다 많아도 과적합이 심하지 않다고전적 bias-variance 곡선으로 설명 안 된다
SGD 로 찾은 해가 특히 잘 일반화된다알고리즘이 해를 고른다 — 암묵적 정규화
$\eta$·$B$·초기화가 성능을 바꾼다최적화 설정이 곧 정규화 설정이다

실무적 결론은 명확하다. training loss 를 더 낮추는 것이 목표가 아니다. train loss 가 이미 충분히 낮은데 validation 이 나쁘면 optimizer 를 바꿀 것이 아니라 정규화·data·구조를 손봐야 한다.

Loss Landscape 손실 지형

수백만 차원의 loss 지형을 볼 수는 없지만, 무작위 방향 두 개를 골라 2차원 단면을 그릴 수 있다. 이때 방향의 스케일을 층별 weight 노름으로 맞추는 filter normalization 을 해야 서로 다른 model 을 비교할 수 있다5.

$$ f(\alpha,\beta) = \mathcal{L}\bigl(\boldsymbol\theta^\star + \alpha\,\mathbf{d}_1 + \beta\,\mathbf{d}_2\bigr) $$
(4)

이 방법으로 관찰된 것들이 딥러닝 최적화에 대한 그림을 크게 바꿨다.

관찰함의
residual connection 이 지형을 매끄럽게 만든다깊은 network 가 학습되는 이유
깊이만 늘리면 지형이 혼돈스러워진다residual 없는 깊은 network 가 학습 안 되는 이유
넓은 model 일수록 지형이 평평하다과매개변수화의 이점
서로 다른 최소점이 낮은 능선으로 연결되어 있다mode connectivity — 고립된 웅덩이가 아니다

Scale Invariance 스케일 불변성

$$ \mathrm{BN}(c\mathbf{W}\mathbf{x}) = \mathrm{BN}(\mathbf{W}\mathbf{x}) \quad\Longrightarrow\quad \mathcal{L}(c\mathbf{W}) = \mathcal{L}(\mathbf{W}), \qquad \nabla\mathcal{L}(c\mathbf{W}) = \tfrac{1}{c}\nabla\mathcal{L}(\mathbf{W}) $$
(5)

BatchNorm·LayerNorm 바로 앞의 weight 는 크기가 함수에 아무 영향을 주지 않는다 — 정규화가 스케일을 지워 버리기 때문이다. 그러면 weight 의 방향만 의미가 있고 크기는 자유롭다. 결과가 흥미롭다.

$$ \eta_{\text{eff}} \;\propto\; \frac{\eta}{\|\mathbf{W}\|^2} $$
(6)

weight 가 커지면 유효 learning rate 가 저절로 줄어든다(유도 3). 학습이 진행되며 $\|\mathbf{W}\|$ 가 커지는 경향이 있으므로, BatchNorm 이 있는 network 는 명시적 schedule 없이도 자동으로 학습률이 감쇠한다.

그리고 이것이 정규화 층이 있을 때 weight decay 의 의미가 달라지는 이유다. weight decay 는 $\|\mathbf{W}\|$ 를 줄이므로 일반화 효과가 아니라 유효 학습률을 올리는 효과로 작동한다6. "BatchNorm 을 쓰는데 weight decay 가 왜 여전히 도움이 되는가"의 답이 여기 있다.

식 (1)의 $\rho^L$ 은 어림이다. 층마다 Jacobian이 다르고, 곱의 노름은 각 노름의 곱보다 작을 수 있다($\|\mathbf{AB}\|\leq\|\mathbf{A}\|\|\mathbf{B}\|$). 정확한 진술은 "곱의 특이값이 지수적으로 갈라진다"에 가깝다. 그래도 지수적으로 커지거나 작아진다는 결론은 견고하며, 실무에서는 층별 gradient norm 을 직접 찍어 보는 것이 가장 확실하다.

5

유도

유도 1 — residual 이 지수적 소멸을 막는다

$$ \text{평범한 층: } \frac{\partial\mathcal{L}}{\partial\mathbf{h}_0} = \bar{\mathbf{h}}_L^\top\prod_{\ell=1}^{L}\mathbf{J}_\ell $$
3.4 식 (2). 곱만 있다
$$ \|\mathbf{J}_\ell\|\approx\rho \;\Longrightarrow\; \left\|\prod\right\| \approx \rho^L $$
$\rho=0.9$, $L=100$ 이면 $2.7\times10^{-5}$
$$ \text{residual: } \mathbf{h}_\ell = \mathbf{h}_{\ell-1}+F_\ell(\mathbf{h}_{\ell-1}) \;\Rightarrow\; \mathbf{J}_\ell = \mathbf{I}+\mathbf{J}_{F_\ell} $$
항등 경로가 더해진다
$$ \prod_{\ell=1}^{L}(\mathbf{I}+\mathbf{J}_{F_\ell}) = \mathbf{I} + \sum_\ell \mathbf{J}_{F_\ell} + \sum_{\ell<m}\mathbf{J}_{F_m}\mathbf{J}_{F_\ell} + \cdots $$
전개하면 $2^L$ 개의 경로가 나온다
$$ \text{첫 항 } \mathbf{I} \ \text{는 } L \ \text{에 무관하다} $$
아무것도 곱해지지 않은 경로가 항상 존재 — 이것이 핵심
$$ \|\mathbf{J}_{F_\ell}\|\ll1 \;\Rightarrow\; \prod \approx \mathbf{I} + \sum_\ell\mathbf{J}_{F_\ell} \quad (\text{덧셈적}) $$
지수적 곱이 선형적 합으로 바뀐다 — 죽지도 터지지도 않는다

유도 2 — clipping 이 방향을 보존한다

$$ \|\mathbf{g}\|>c \;\Longrightarrow\; \hat{\mathbf{g}} = \frac{c}{\|\mathbf{g}\|}\mathbf{g} = s\,\mathbf{g}, \quad s=\frac{c}{\|\mathbf{g}\|}\in(0,1) $$
모든 성분에 같은 양수 $s$ 를 곱한다
$$ \frac{\hat{\mathbf{g}}}{\|\hat{\mathbf{g}}\|} = \frac{s\mathbf{g}}{s\|\mathbf{g}\|} = \frac{\mathbf{g}}{\|\mathbf{g}\|} $$
단위 vector 가 동일 — 방향이 정확히 보존된다
$$ \|\hat{\mathbf{g}}\| = \frac{c}{\|\mathbf{g}\|}\|\mathbf{g}\| = c $$
크기는 정확히 $c$ 로 맞춰진다
$$ \text{value clipping: } \hat{g}_i = \mathrm{clip}(g_i,-v,v) $$
성분마다 다르게 잘린다
$$ \mathbf{g}=(100,\ 1) \;\Rightarrow\; \hat{\mathbf{g}}=(1,\ 1) \quad (v=1) $$
비율이 $100{:}1$ 에서 $1{:}1$ 로 — 방향이 완전히 바뀌었다
$$ \text{norm clipping: } (100,1) \to \tfrac{1}{100.005}(100,1) \approx (0.99995,\ 0.00999) $$
비율 $100{:}1$ 이 그대로 유지된다 ✓

유도 3 — scale invariance 가 유효 학습률을 정한다

$$ \mathcal{L}(c\mathbf{W}) = \mathcal{L}(\mathbf{W}) \quad \forall c>0 $$
BatchNorm 앞 weight 의 성질 (식 5)
$$ \frac{d}{dc}\mathcal{L}(c\mathbf{W}) = \nabla\mathcal{L}(c\mathbf{W})^\top\mathbf{W} = 0 $$
양변을 $c$ 로 미분. gradient 가 $\mathbf{W}$ 에 수직이다
$$ \nabla\mathcal{L}(c\mathbf{W}) = \frac{1}{c}\nabla\mathcal{L}(\mathbf{W}) $$
1차 동차성. 스케일이 커지면 gradient 는 작아진다
$$ \Delta(c\mathbf{W}) = -\eta\,\frac{1}{c}\nabla\mathcal{L}(\mathbf{W}) $$
한 스텝의 절대 변화량
$$ \frac{\|\Delta(c\mathbf{W})\|}{\|c\mathbf{W}\|} = \frac{\eta\|\nabla\mathcal{L}\|/c}{c\|\mathbf{W}\|} = \frac{1}{c^2}\cdot\frac{\eta\|\nabla\mathcal{L}\|}{\|\mathbf{W}\|} $$
상대적 변화가 $1/c^2$ — 방향이 바뀌는 속도다
$$ \therefore\ \eta_{\text{eff}} \propto \frac{\eta}{\|\mathbf{W}\|^2} $$
weight 가 커지면 저절로 학습률이 준다
$$ \text{weight decay: } \|\mathbf{W}\|\downarrow \;\Longrightarrow\; \eta_{\text{eff}}\uparrow $$
정규화 층이 있으면 weight decay 는 학습률 조절 장치로 작동한다
gradient 가 $\mathbf{W}$ 에 수직이라는 것의 기하적 의미

유도 3 의 두 번째 줄은 $\nabla\mathcal{L}^\top\mathbf{W}=0$ 을 말한다. 즉 gradient 는 $\mathbf{W}$ 의 방향을 바꾸는 성분만 갖고 크기를 바꾸는 성분은 0 이다. 파라미터가 반지름 $\|\mathbf{W}\|$ 인 구면 위에서만 움직인다는 뜻이다.

그런데 실제로는 $\|\mathbf{W}\|$ 가 학습 중에 커진다. gradient 자체는 접선 방향이지만 $\mathbf{W}+\Delta$ 의 노름은 피타고라스 정리에 의해 $\sqrt{\|\mathbf{W}\|^2+\|\Delta\|^2} > \|\mathbf{W}\|$ 이기 때문이다. 그래서 정규화 층이 있는 network 는 weight 노름이 단조 증가하고 유효 학습률이 저절로 감쇠한다. weight decay 는 이 증가를 상쇄해 유효 학습률을 일정 수준으로 유지하는 역할을 한다 — 겉보기와 달리 정규화가 아니라 스케줄링에 가깝다.

② Gradient Clipping 을 손으로

$\mathbf{g}=(100,\ 1)^\top$, $c=1$ 로 두 방식을 비교한다.

$$ \|\mathbf{g}\| = \sqrt{100^2+1^2} = \sqrt{10001} \approx 100.005 $$
전체 노름
$$ s = \frac{c}{\|\mathbf{g}\|} = \frac{1}{100.005} \approx 0.0099995 $$
축소 배율
$$ \hat{\mathbf{g}} = (0.99995,\ 0.0099995)^\top, \qquad \|\hat{\mathbf{g}}\| = 1 \ \checkmark $$
norm clipping. 비율 $100{:}1$ 유지
$$ \text{value clipping } (v=1): \ \hat{\mathbf{g}} = (1,\ 1)^\top $$
각 성분을 개별적으로 자른다
$$ \cos\theta = \frac{100\cdot1+1\cdot1}{100.005\cdot\sqrt2} = \frac{101}{141.43} \approx 0.714 \;\Rightarrow\; \theta \approx 44.4° $$
방향이 44도나 틀어졌다 — value clipping 의 대가
$$ \text{norm clipping 의 } \cos\theta = 1 \;\Rightarrow\; \theta = 0° $$
완전히 같은 방향 (유도 2)

③ Sharp vs Flat — 밀림에 대한 민감도

두 최소점을 $\mathcal{L}(w)=\tfrac12 a w^2$ 로 model 한다. sharp 는 $a=100$, flat 은 $a=1$.

$$ \text{둘 다 } w=0 \text{ 에서 } \mathcal{L}=0 \quad (\text{train loss 가 같다}) $$
학습 결과만 보면 구분이 안 된다
$$ \text{test 곡면이 } \delta=0.1 \text{ 만큼 밀렸다고 하자: } \mathcal{L}_{\text{test}}(w) = \tfrac12 a(w-\delta)^2 $$
분포 차이를 최소점의 이동으로 model 한 것
$$ \text{sharp: } \mathcal{L}_{\text{test}}(0) = \tfrac12\times100\times0.01 = 0.5 $$
$a=100$, $\delta^2=0.01$
$$ \text{flat: } \mathcal{L}_{\text{test}}(0) = \tfrac12\times1\times0.01 = 0.005 $$
100배 차이 — 같은 train loss 인데
$$ \delta=0.3: \ \text{sharp } 4.5 \quad\text{vs}\quad \text{flat } 0.045 $$
밀림이 커지면 격차도 커진다 (둘 다 $\delta^2$ 에 비례)
$$ \text{일반화 갭} = \mathcal{L}_{\text{test}} - \mathcal{L}_{\text{train}} = \tfrac12 a\delta^2 \;\propto\; a $$
갭이 곡률 $a$ 에 비례한다는 것이 sharp/flat 논지의 핵심

④ Scale invariance 를 숫자로

$$ \|\mathbf{W}\| = 1, \quad \|\nabla\mathcal{L}\| = 0.1, \quad \eta = 0.01 $$
기준 상태
$$ \text{상대 변화} = \frac{0.01\times0.1}{1} = 10^{-3} $$
한 스텝에 방향이 0.1% 정도 돈다
$$ \mathbf{W}\to2\mathbf{W}: \ \|\nabla\mathcal{L}\| \to \frac{0.1}{2}=0.05, \quad \|\mathbf{W}\|=2 $$
gradient 는 절반, 노름은 2배 (유도 3)
$$ \text{상대 변화} = \frac{0.01\times0.05}{2} = 2.5\times10^{-4} $$
정확히 1/4 — $1/c^2$ ✓
$$ \text{함수 자체는? } \mathcal{L}(2\mathbf{W}) = \mathcal{L}(\mathbf{W}) \ \text{— 전혀 안 변함} $$
같은 model 인데 학습 속도만 4배 느려졌다
$$ \text{weight decay } \lambda: \ \|\mathbf{W}\|\downarrow \;\Rightarrow\; \eta_{\text{eff}}\uparrow $$
그래서 BatchNorm 이 있어도 weight decay 가 성능을 바꾼다

8

흔한 오해와 함정

오해 1

"gradient clipping 을 걸었으니 exploding gradient 는 해결됐다."

실제로는 clipping 은 증상을 가릴 뿐이다. gradient norm 이 계속 임계값에 붙어 있다면 실제 gradient 는 훨씬 크다는 뜻이고, 그러면 매 스텝 같은 크기로 움직이게 되어 학습이 왜곡된다. clip 비율(잘린 스텝의 비율)을 로그로 찍어 보고, 계속 높으면 초기화·정규화·$\eta$·구조 쪽을 손봐야 한다.

오해 2

"flat minimum 이 항상 더 잘 일반화한다."

실제로는 반례가 있다. ReLU network 를 재매개변수화하면 함수는 그대로인 채 sharpness 만 임의로 바꿀 수 있다3. 한 층에 $c$ 를 곱하고 다음 층을 $1/c$ 로 나누면 같은 model 인데 Hessian eigenvalue 가 달라진다. 실무 지침으로는 유용하지만 정리로 인용해서는 안 된다. 스케일에 불변인 sharpness 척도를 써야 의미 있는 비교가 된다.

오해 3

"큰 batch 는 일반화가 나쁘다."

실제로는 $\eta$ 를 함께 조정하지 않았을 때 나쁘다. linear scaling + warmup 을 적용하면 $B=8192$ 로도 정확도 손실 없이 학습된다4. 잡음 세기 $\eta/B$ 를 일정하게 유지하는 것이 요령이다(예제 ⑤). 다만 critical batch size 를 넘으면 GPU 를 더 써도 학습이 빨라지지 않는 한계는 실재한다.

오해 4

"BatchNorm 을 쓰면 weight decay 는 의미가 없다."

실제로는 의미가 달라질 뿐 없어지지 않는다. 정규화 층 앞의 weight 는 크기가 함수에 영향이 없지만(식 5), 유효 학습률 $\eta/\|\mathbf{W}\|^2$ 를 통해 학습 속도에 영향을 준다6. weight decay 는 $\|\mathbf{W}\|$ 를 눌러 유효 학습률을 유지하는 장치로 작동하며, 실제로 끄면 성능이 떨어진다. 겉보기와 달리 정규화가 아니라 스케줄링에 가깝다.

오해 5

"train loss 가 안 떨어지면 optimizer 를 바꾼다."

실제로는 optimizer 는 gradient 를 재활용할 뿐 없는 신호를 만들지 못한다 (3.7 오해 5). gradient 가 죽었으면(vanishing) 어떤 optimizer 도 소용없다. 점검 순서는 층별 gradient norm → 초기화 → 정규화·residual → learning rate → 마지막에 optimizer 다. '수식과 기호'의 진단표가 이 순서를 정리한 것이다.

코드로 확인

예제 ①–④ 를 검증한다.

NumPy — 깊이별 gradient · clipping · sharpness · scale invariance (20줄) 
import numpy as np

for rho in [0.25, 0.9, 1.0, 1.1, 1.5]:
    print(rho, [f"{rho**L:.2e}" for L in (5, 10, 50, 100)])
# 0.9  -> ... 2.66e-05  /  1.1 -> ... 1.38e+04    같은 거리인데 정반대로

g = np.array([100., 1.])
gn = g * min(1.0, 1.0 / np.linalg.norm(g))          # norm clipping
gv = np.clip(g, -1.0, 1.0)                          # value clipping
cos = lambda a, b: a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
print(gn.round(5), round(float(cos(g, gn)), 6))     # [0.99995 0.01] 1.0     방향 보존
print(gv, round(np.degrees(np.arccos(cos(g, gv))), 1))  # [1. 1.] 44.4      44도 틀어짐

for a, name in [(100., "sharp"), (1., "flat")]:     # 밀림 δ 에 대한 test loss
    print(name, [round(0.5 * a * d**2, 4) for d in (0.1, 0.3)])
# sharp [0.5, 4.5]  /  flat [0.005, 0.045]    100배 차이

W, gradW, eta = 1.0, 0.1, 0.01                      # scale invariance
for c in [1., 2., 4.]:
    rel = eta * (gradW / c) / (c * W)               # 상대 변화량
    print(c, f"{rel:.3e}", round(rel * c * c / (eta * gradW / W), 3))
# 1 1.000e-03 1.0 / 2 2.500e-04 1.0 / 4 6.250e-05 1.0   <- 정확히 1/c²

마지막 열이 전부 1.0 인 것은 상대 변화량이 정확히 $1/c^2$ 로 줄어든다는 뜻이다 — 유도 3 을 숫자로 확인한 것이다.

자가 점검

계산 층마다 gradient 가 0.9배가 된다. 100층을 지나면 대략 몇 배?

풀이 · $0.9^{100} = e^{100\ln0.9} = e^{-10.54} \approx 2.66\times10^{-5}$. 다는 $0.9\times100$ 으로 곱셈을 덧셈처럼 다룬 오답이다. 반복은 거듭제곱이라는 것이 이 절 전체의 출발점이며, 1 에서 0.1 밖에 안 벗어났는데 십만분의 3 이 된다.

계산 $\mathbf{g}=(3,4)^\top$ 을 $c=1$ 로 norm clipping 하면?

풀이 · $\|\mathbf{g}\|=5>1$ 이므로 $s=1/5=0.2$ 를 곱해 $(0.6,0.8)$. 노름이 정확히 1 이고 비율 $3{:}4$ 가 유지된다. 나는 value clipping 의 결과로, 비율이 $1{:}1$ 이 되어 방향이 바뀐다(유도 2).

계산 BatchNorm 앞 weight 를 3배로 키우면 유효 학습률은?

풀이 · $\eta_{\text{eff}} \propto \eta/\|\mathbf{W}\|^2$ 이므로 $1/3^2=1/9$ (유도 3). gradient 가 $1/3$ 로 줄고($1/c$), 상대 변화를 재려면 다시 $\|\mathbf{W}\|$ 로 나누므로 제곱이 된다. 나는 한 번만 나눈 답이다. 함수는 전혀 안 변했는데 학습 속도만 9배 느려진다.

개념 residual connection 이 vanishing gradient 를 완화하는 이유는?

풀이 · $\prod(\mathbf{I}+\mathbf{J}_{F_\ell}) = \mathbf{I}+\sum\mathbf{J}_{F_\ell}+\cdots$ 에서 첫 항 $\mathbf{I}$ 가 $L$ 에 무관하게 살아남는다(유도 1). 지수적 곱이 덧셈적 합으로 바뀌는 것이 핵심이다. 나는 사실과 반대다 — residual 은 파라미터를 늘리지 줄이지 않는다.

개념 $B$ 를 256 에서 8192 로 32배 늘렸다. 잡음 세기 $\eta/B$ 를 유지하려면?

풀이 · $\eta/B$ 를 일정하게 두려면 분자도 32배가 되어야 한다 — linear scaling rule(예제 ⑤). 다만 커진 $\eta$ 를 처음부터 쓰면 발산하므로 warmup 이 필수다. 다가 흔한 실수이며, 이렇게 해 놓고 "큰 batch 가 나쁘다"고 결론 내리는 실험이 많다.

함정 "flat minimum 이 일반화가 좋다"의 가장 정확한 한계는?

풀이 · 한 층에 $c$ 를 곱하고 다음 층을 $1/c$ 로 나누면 같은 함수인데 Hessian eigenvalue 가 바뀐다 — sharpness 가 함수의 성질이 아니라 매개변수화의 성질이라는 뜻이다(오해 2). 나는 틀렸다 — Hessian-vector product 로 최대 eigenvalue 는 계산할 수 있다. 스케일 불변 척도로 재면 상관관계가 유지된다는 후속 연구가 있어, 방향 자체가 무의미하지는 않다.
