1

한 줄 요약

판별 model 이 경계 $p(y\mid\mathbf{x})$ 를 배우는 동안, 생성 model 은 각 class 가 data 를 어떻게 만들어 내는지 $p(\mathbf{x}\mid y)$ 를 배우고 Bayes 정리로 뒤집는다. 보이지 않는 잠재변수가 끼면 우도를 직접 못 풀므로 EM — 기대(E)와 최대화(M)를 번갈아 — 로 푼다.

학습 목표

  1. naive Bayes 의 독립 가정이 무엇을 사게 하고 무엇을 잃게 하는지 설명하고 손으로 분류할 수 있다.
  2. GDA 의 결정 경계가 공분산 가정에 따라 선형/이차가 되는 이유를 유도할 수 있다.
  3. GMM 에 EM 을 적용해 한 라운드를 손으로 계산하고, 우도가 단조 증가함을 설명할 수 있다.
2

직관

스팸 분류를 두 가지 방식으로 생각해 볼 수 있다. 판별은 "이 메일이 스팸인지 아닌지 가르는 선을 긋자"이고 (5.4·5.8), 생성은 "스팸은 어떤 단어를 어떤 빈도로 쓰는가, 정상 메일은 어떤가"를 각각 배운 뒤 어느 쪽이 이 메일을 더 잘 설명하는지 비교하는 것이다.

생성 방식이 더 많은 일을 한다 — 새 표본을 만들어 낼 수 있고, 결측치를 자연스럽게 다루며, class 하나만 보고도 학습할 수 있다. 대가로 $p(\mathbf{x}\mid y)$ 라는 훨씬 어려운 것을 가정해야 하고, 그 가정이 틀리면 곧바로 손해로 돌아온다.

한 걸음 더 나아가, class label 조차 안 보인다면? "이 data 는 몇 개의 무리에서 나왔다"고만 가정하고 어느 점이 어느 무리에서 왔는지를 숨은 변수로 둔다. 닭이 먼저냐 달걀이 먼저냐 — 무리를 알면 parameter 를 구할 수 있고, parameter 를 알면 무리를 알 수 있다. EM 은 이 둘을 번갈아 돌린다.

쉬운 말로

두 사람의 필체를 구분한다고 합시다. 판별은 "ㄱ 의 각도가 40도보다 크면 A" 같은 규칙을 찾습니다. 생성은 "A 는 이런 식으로 쓰고, B 는 저런 식으로 쓴다"고 각자의 습관 자체를 익힌 뒤, 새 글씨를 보고 "누구 습관에 더 가까운가"를 묻습니다.

생성 쪽을 익히면 A 의 필체를 흉내 내 쓸 수도 있습니다. 판별 쪽은 그렇게 못 합니다 — 경계만 알지 습관은 모르니까요.

형식적 정의

생성 model 의 기본 틀

$$ p(y\mid\mathbf{x})=\frac{p(\mathbf{x}\mid y)\,p(y)}{\sum_{c}p(\mathbf{x}\mid c)\,p(c)}, \qquad \hat{y}=\arg\max_c\ p(\mathbf{x}\mid c)\,p(c) $$
(1)

생성 model 은 class 별 분포 $p(\mathbf{x}\mid y)$ 와 사전확률 $p(y)$ 를 학습하고, 4.1의 Bayes 정리로 뒤집어 분류한다 — 분모는 class 에 무관하므로 비교할 때는 무시한다.

Naive Bayes

$$ p(\mathbf{x}\mid y)=\prod_{j=1}^{d}p(x_j\mid y) \qquad \Longrightarrow \qquad \hat{y}=\arg\max_c\ \Bigl[\log p(c)+\sum_j\log p(x_j\mid c)\Bigr] $$
(2)

naive Bayes 는 class 를 알면 feature 들이 서로 독립이라고 가정한다 — $d$차원 결합분포 하나를 1차원 분포 $d$개로 쪼개므로 parameter 수가 지수적에서 선형으로 줄어든다.

변형$p(x_j\mid y)$쓰는 곳
Gaussian NB$\mathcal{N}(\mu_{jc},\sigma_{jc}^2)$연속형 feature
Multinomial NB단어 빈도 (다항분포)텍스트 분류
Bernoulli NB단어 출현 여부짧은 문서
Complement NB보완 class 로 추정불균형 텍스트

로그를 취하는 것이 필수다 — $d$가 수천이면 확률의 곱이 부동소수점 하한 아래로 언더플로해 0 이 된다. 또 훈련에서 못 본 조합이 있으면 확률이 0 이 되어 곱 전체가 0 이 되므로, Laplace 평활($\alpha$ 를 더해 주는 것)이 사실상 필수다.

$$ \hat{p}(x_j=v\mid c)=\frac{N_{jvc}+\alpha}{N_c+\alpha V} \qquad (\alpha=1 \text{ 이 Laplace}) $$
(3)

GDA (Gaussian Discriminant Analysis)

$$ p(\mathbf{x}\mid y=c)=\mathcal{N}(\boldsymbol{\mu}_c,\boldsymbol{\Sigma}_c), \qquad \boldsymbol{\Sigma}_c=\boldsymbol{\Sigma}\ \text{(공유)} \Rightarrow \textbf{선형 경계} $$
(4)

GDA 는 각 class 를 다변량 정규분포로 두며, 공분산을 공유하면 이차항이 상쇄되어 경계가 직선(LDA)이 되고, 따로 두면 이차 곡선(QDA)이 된다(유도 1).

LDA (공유 $\boldsymbol{\Sigma}$)QDA (class 별 $\boldsymbol{\Sigma}_c$)
경계직선/초평면이차 곡선 (타원·쌍곡선)
parameter 수$Kd+d(d+1)/2$$Kd+Kd(d+1)/2$

필요 표본적다많다 — class 당 $d$ 이상 필수

차원 축소$K-1$ 차원으로 사영 가능불가

표의 마지막 줄 "$K-1$ 차원으로 사영 가능" 은 유도 1 의 부산물이다. 경계가 $\mathbf{w}^\top\mathbf{x}+b$ 꼴이고 $\mathbf{w}=\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)$ 이므로, 분류에 필요한 정보가 이 한 방향에 전부 실려 있다 — 나머지 방향은 두 class 를 가르는 데 아무 기여도 하지 않는다. class 가 $K$개면 중심들이 만드는 부분공간이 $K-1$ 차원이라 그만큼 남는다.

$$ \mathbf{S}_W=\sum_c\sum_{i\in c}(\mathbf{x}_i-\boldsymbol{\mu}_c)(\cdot)^\top, \quad \mathbf{S}_B=\sum_c n_c(\boldsymbol{\mu}_c-\bar{\mathbf{x}})(\cdot)^\top \ \Rightarrow\ \mathbf{S}_W^{-1}\mathbf{S}_B \text{ 의 상위 } K-1 \text{ 개 고유vector} $$
(4b)

즉 class 안의 흩어짐 $\mathbf{S}_W$ 대비 class 사이의 벌어짐 $\mathbf{S}_B$ 를 최대로 하는 방향들을 고르는 것이고, 2-class 면 그 답이 정확히 $\mathbf{S}_W^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)$ 하나다. 2.9·5.11의 PCA 가 label 을 안 보고 분산이 큰 방향을 고르는 것과 달리, 이쪽은 label 을 보고 판별에 쓸모 있는 방향을 고른다 — 5.11 오해 2 가 "label 을 쓰는 축소가 필요하면 LDA"라고 한 것이 이 절차다. 축소한 차원이 $K-1$ 로 묶이는 것이 한계이며, class 가 둘이면 1차원밖에 못 얻는다.

GDA 와 logistic regression 은 같은 형태의 posterior 를 낳는다 — GDA 가정이 맞으면 posterior 가 정확히 sigmoid 가 되지만, 그 역은 성립하지 않는다(유도 1). 즉 GDA 가 더 강한 가정이고, 그것이 맞으면 표본이 적을 때 더 효율적, 틀리면 logistic regression 이 낫다 — 5.1의 편향-분산 맞바꿈이 다시 나타나는 자리다.

Latent Variable & GMM

$$ p(\mathbf{x})=\sum_{k=1}^{K}\pi_k\,\mathcal{N}(\mathbf{x}\mid\boldsymbol{\mu}_k,\boldsymbol{\Sigma}_k), \qquad \sum_k\pi_k=1,\ \pi_k\ge0 $$
(5)

잠재변수는 관측되지 않지만 data 를 설명하는 데 필요한 변수다. GMM 에서는 "이 점이 어느 봉우리에서 나왔는가"인 $z_i\in\{1..K\}$ 가 잠재변수이고, 그것을 주변화(합)해 없앤 것이 식 (5)다.

$$ \log p(X\mid\theta)=\sum_i\log\Bigl[\sum_k\pi_k\mathcal{N}(\mathbf{x}_i\mid\boldsymbol{\mu}_k,\boldsymbol{\Sigma}_k)\Bigr] \quad \leftarrow\ \textbf{로그 안에 합이 있다} $$
(6)

식 (6)의 "로그 안의 합" 이 모든 어려움의 근원이다. 4.6에서 봤듯 로그가 곱을 합으로 바꿔 주어야 미분이 쉬운데, 여기서는 로그가 합을 만나 분리되지 않는다 — 닫힌 해가 없다. $z_i$ 를 알기만 하면 각 봉우리마다 따로 평균·분산을 구하면 끝인데, 그것이 안 보인다.

EM Algorithm

$$ \textbf{E-step: } \gamma_{ik}=\frac{\pi_k\mathcal{N}(\mathbf{x}_i\mid\boldsymbol{\mu}_k,\boldsymbol{\Sigma}_k)}{\sum_{k'}\pi_{k'}\mathcal{N}(\mathbf{x}_i\mid\boldsymbol{\mu}_{k'},\boldsymbol{\Sigma}_{k'})} \qquad \textbf{M-step: } \boldsymbol{\mu}_k=\frac{\sum_i\gamma_{ik}\mathbf{x}_i}{\sum_i\gamma_{ik}} $$
(7)

EM 은 보이지 않는 $z$ 를 현재 parameter 로 추측하고(E), 그 추측을 사실인 양 여겨 parameter 를 갱신한다(M) — 이를 번갈아 반복하며, 우도가 절대 줄지 않는다는 것이 보장된다(유도 2)1.

단계고정갱신뜻
E$\theta$$\gamma_{ik}$ (책임도)"점 $i$ 가 봉우리 $k$ 에서 왔을 확률"
M$\gamma_{ik}$$\pi_k,\boldsymbol{\mu}_k,\boldsymbol{\Sigma}_k$책임도로 가중한 평균·분산
$$ \pi_k=\frac{N_k}{n}, \qquad \boldsymbol{\Sigma}_k=\frac{1}{N_k}\sum_i\gamma_{ik}(\mathbf{x}_i-\boldsymbol{\mu}_k)(\mathbf{x}_i-\boldsymbol{\mu}_k)^\top, \qquad N_k=\sum_i\gamma_{ik} $$
(8)

k-means 는 EM 의 특수한 경우다 — 책임도를 0/1 로 딱딱하게 자르고 공분산을 $\sigma^2\mathbf{I}$ 로 고정하면 정확히 k-means 가 된다(5.10). GMM 은 "부드러운 k-means" 인 셈이고, 그래서 타원형 무리와 겹친 무리를 다룰 수 있다.

HMM (Hidden Markov Model)

$$ p(\mathbf{x}_{1:T},z_{1:T})=p(z_1)\prod_{t=2}^{T}\underbrace{A_{z_{t-1}z_t}}_{\text{전이}}\prod_{t=1}^{T}\underbrace{B_{z_t}(\mathbf{x}_t)}_{\text{방출}} $$
(9)

HMM 은 잠재변수가 시간에 따라 이어지는 model 이다 — 숨은 상태가 Markov 사슬을 따라 옮겨 다니고, 각 상태에서 관측을 방출한다. GMM 에 시간축을 붙인 것으로 볼 수 있다.

세 가지 문제묻는 것알고리즘비용
평가$p(\mathbf{x}_{1:T})$ 는?forward$O(TK^2)$
복호가장 그럴듯한 상태열은?Viterbi$O(TK^2)$
학습$A,B,\pi$ 는?Baum-Welch (= EM)반복 × $O(TK^2)$

Viterbi 와 forward 는 같은 동적계획법의 두 변형이다 — 합($\sum$) 대신 최대($\max$)를 쓰면 Viterbi 가 된다. 순진하게 하면 상태열이 $K^T$ 개라 $T=100,K=5$ 만 되어도 계산이 불가능한데, Markov 성질 덕분에 $t$ 시점까지의 요약이 $K$개 숫자로 충분해 $O(TK^2)$ 로 줄어든다.

HMM 은 음성 인식과 형태소 분석의 표준이었고 지금은 대부분 신경망에 자리를 내주었지만, 생물정보학(유전자 영역 탐지)·금융 국면 전환·활동 인식처럼 상태 자체가 해석 대상이고 표본이 적은 곳에서는 여전히 현역이다. 구조적으로는 4.10의 자기회귀 model 및 상태공간 model 과 한 계보다.

유도

유도 1 — GDA 의 경계가 선형이 되는 조건

$$ \log\frac{p(y=1\mid\mathbf{x})}{p(y=0\mid\mathbf{x})}=\log\frac{p(\mathbf{x}\mid1)}{p(\mathbf{x}\mid0)}+\log\frac{\pi_1}{\pi_0} $$
Bayes 정리에서 분모가 상쇄된다 — 5.4의 log-odds
$$ \log p(\mathbf{x}\mid c)=-\tfrac12(\mathbf{x}-\boldsymbol{\mu}_c)^\top\boldsymbol{\Sigma}_c^{-1}(\mathbf{x}-\boldsymbol{\mu}_c)-\tfrac12\log|\boldsymbol{\Sigma}_c|+\text{const} $$
다변량 정규분포의 로그 (4.4)
$$ \boldsymbol{\Sigma}_1=\boldsymbol{\Sigma}_0=\boldsymbol{\Sigma}\ \Rightarrow\ \mathbf{x}^\top\boldsymbol{\Sigma}^{-1}\mathbf{x} \text{ 항이 } \textbf{양쪽에서 같아 상쇄} $$
여기가 핵심 — 이차항이 사라진다
$$ \log\frac{p_1}{p_0}=\underbrace{(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)^\top\boldsymbol{\Sigma}^{-1}}_{\mathbf{w}^\top}\mathbf{x}+\underbrace{\bigl[-\tfrac12(\boldsymbol{\mu}_1^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_1-\boldsymbol{\mu}_0^\top\boldsymbol{\Sigma}^{-1}\boldsymbol{\mu}_0)+\log\tfrac{\pi_1}{\pi_0}\bigr]}_{b} $$
$\mathbf{x}$ 에 대해 정확히 선형 — 식 (4)
$$ \Rightarrow\ p(y=1\mid\mathbf{x})=\sigma(\mathbf{w}^\top\mathbf{x}+b) $$
log-odds 가 선형이면 posterior 는 sigmoid — logistic regression 과 같은 형태
$$ \text{역은 성립하지 않는다} \ (\text{sigmoid 라고 정규분포는 아니다}) $$
GDA 가 더 강한 가정 — Poisson 등 여러 분포가 같은 sigmoid 를 낸다
$$ \boldsymbol{\Sigma}_1\ne\boldsymbol{\Sigma}_0 \ \Rightarrow\ \mathbf{x}^\top(\boldsymbol{\Sigma}_1^{-1}-\boldsymbol{\Sigma}_0^{-1})\mathbf{x} \text{ 가 남는다} $$
이차 경계(QDA) — 타원·쌍곡선·평행선이 될 수 있다

유도 2 — EM 이 우도를 줄이지 않는 이유

$$ \log p(X\mid\theta)=\log\sum_Z p(X,Z\mid\theta)=\log\sum_Z q(Z)\frac{p(X,Z\mid\theta)}{q(Z)} $$
임의의 분포 $q(Z)$ 를 곱하고 나눴다 (중요도 가중)
$$ \ge\ \sum_Z q(Z)\log\frac{p(X,Z\mid\theta)}{q(Z)}\ \equiv\ \mathcal{L}(q,\theta) $$
Jensen 부등식 — 로그가 오목이라 로그의 기댓값 ≥ 기댓값의 로그. 이것이 ELBO
$$ \log p(X\mid\theta)-\mathcal{L}(q,\theta)=\mathrm{KL}\bigl(q(Z)\,\|\,p(Z\mid X,\theta)\bigr)\ \ge\ 0 $$
차이가 정확히 KL 발산 (4.7)
$$ \textbf{E-step}:\ q^{(t)}(Z)=p(Z\mid X,\theta^{(t)}) \ \Rightarrow\ \mathrm{KL}=0 \ \Rightarrow\ \mathcal{L}=\log p(X\mid\theta^{(t)}) $$
하계가 현재 점에서 우도에 딱 닿는다 — 이것이 책임도 $\gamma_{ik}$ 계산의 정체
$$ \textbf{M-step}:\ \theta^{(t+1)}=\arg\max_\theta\mathcal{L}(q^{(t)},\theta) \ \Rightarrow\ \mathcal{L}(q^{(t)},\theta^{(t+1)})\ge\mathcal{L}(q^{(t)},\theta^{(t)}) $$
하계를 올린다. $q$ 를 고정하면 로그 안의 합이 사라져 닫힌 해가 나온다
$$ \log p(X\mid\theta^{(t+1)})\ \ge\ \mathcal{L}(q^{(t)},\theta^{(t+1)})\ \ge\ \mathcal{L}(q^{(t)},\theta^{(t)})=\log p(X\mid\theta^{(t)}) $$
우도가 절대 줄지 않는다 ∎ — 두 부등식을 이었다
$$ \text{단, } \textbf{국소 최대} \text{ 로 수렴할 뿐 전역 최대는 아니다} $$
그래서 여러 초기값에서 돌려 가장 좋은 것을 고른다(n_init)

유도 3 — naive Bayes 의 결정 함수가 선형인 경우

$$ \log\frac{p(y=1\mid\mathbf{x})}{p(y=0\mid\mathbf{x})}=\log\frac{\pi_1}{\pi_0}+\sum_j\log\frac{p(x_j\mid1)}{p(x_j\mid0)} $$
식 (2)에 로그를 취했다 — feature 별 기여의 합
$$ \text{Bernoulli NB}:\ p(x_j\mid c)=\theta_{jc}^{x_j}(1-\theta_{jc})^{1-x_j} $$
$x_j\in\{0,1\}$ (단어 출현 여부)
$$ \log\frac{p(x_j\mid1)}{p(x_j\mid0)}=x_j\log\frac{\theta_{j1}(1-\theta_{j0})}{\theta_{j0}(1-\theta_{j1})}+\log\frac{1-\theta_{j1}}{1-\theta_{j0}} $$
지수를 내리고 정리 — $x_j$ 에 대해 1차
$$ \Rightarrow\ \log\text{-odds}=\mathbf{w}^\top\mathbf{x}+b,\qquad w_j=\log\frac{\theta_{j1}(1-\theta_{j0})}{\theta_{j0}(1-\theta_{j1})} $$
naive Bayes 도 선형 분류기다 — 경계의 모양은 logistic regression 과 같다
$$ \text{차이는 } \mathbf{w} \textbf{ 를 구하는 방법}:\ \text{NB 는 세어서, LR 은 조건부 우도 최적화로} $$
NB 는 한 번 훑으면 끝이라 아주 빠르고, LR 은 반복이 필요하다
$$ \Rightarrow\ \text{독립 가정이 깨지면 } \mathbf{w} \text{ 가 } \textbf{편향}\text{되지만 경계 자체는 여전히 선형} $$
확률값은 엉망이어도 순위(argmax)는 자주 맞는다 — 오해 1
naive Bayes 가 왜 그렇게 자주 잘 작동하는가

독립 가정은 텍스트에서 명백히 거짓이다 — "뉴욕"의 "뉴"와 "욕"은 독립이 아니고, "무료"와 "당첨"은 함께 나타난다. 그런데도 스팸 필터의 표준이었다.

이유는 분류가 argmax 만 필요로 하기 때문이다. 상관된 feature 를 여러 번 세면 증거를 중복 계산해 확률이 0 또는 1 쪽으로 극단화되지만, 어느 class 가 더 큰가라는 순위는 잘 보존된다.

그래서 분류 정확도는 좋은데 확률은 신뢰할 수 없다는 특유의 성질이 나온다. predict 는 믿을 만하지만 predict_proba 는 4.9의 보정 없이 그대로 쓰면 안 된다.

또 $d$ 가 크고 $n$ 이 작을 때 — 텍스트가 정확히 그렇다 — 강한 가정이 오히려 분산을 크게 줄여 이득이 된다. 5.2의 편향-분산 맞바꿈이 극단적으로 나타나는 사례다.

① Naive Bayes 로 스팸 분류를 손으로

훈련: 스팸 6통 · 정상 4통. 단어 "무료"는 스팸 5통 / 정상 1통, "회의"는 스팸 1통 / 정상 3통에 나왔다. Bernoulli NB, $\alpha=1$ 로 평활한다.

$$ \pi_{\text{스팸}}=\tfrac{6}{10}=0.6,\qquad \pi_{\text{정상}}=0.4 $$
사전확률
$$ p(\text{무료}\mid\text{스팸})=\frac{5+1}{6+2}=\frac68=0.75,\qquad p(\text{무료}\mid\text{정상})=\frac{1+1}{4+2}=\frac26=0.3333 $$
식 (3). 분모의 $+2$ 는 있음/없음 두 값이라 $\alpha V=1\times2$
$$ p(\text{회의}\mid\text{스팸})=\frac{1+1}{8}=0.25,\qquad p(\text{회의}\mid\text{정상})=\frac{3+1}{6}=0.6667 $$
$$ \text{메일 = \{무료 있음, 회의 없음\}}:\ \ \text{스팸 점수}=0.6\times0.75\times(1-0.25) $$
식 (2). "회의 없음"이므로 $1-p$
$$ =0.6\times0.75\times0.75=0.3375 $$
$$ \text{정상 점수}=0.4\times0.3333\times(1-0.6667)=0.4\times0.3333\times0.3333=0.04444 $$
$$ p(\text{스팸}\mid\mathbf{x})=\frac{0.3375}{0.3375+0.04444}=\frac{0.3375}{0.38194}=0.8836 $$
식 (1)의 정규화 — 스팸으로 분류
$$ \text{평활이 없었다면}:\ \text{“회의”가 스팸에 0번이었을 때 } p=0 \ \Rightarrow\ \textbf{곱 전체가 0} $$
단어 하나가 판단을 독점한다 — 평활이 필수인 이유

② GDA — 선형 경계를 손으로

$\boldsymbol{\mu}_0=(0,0)$, $\boldsymbol{\mu}_1=(2,2)$, $\boldsymbol{\Sigma}=\mathbf{I}$ (공유), $\pi_0=\pi_1=0.5$.

$$ \mathbf{w}=\boldsymbol{\Sigma}^{-1}(\boldsymbol{\mu}_1-\boldsymbol{\mu}_0)=\mathbf{I}(2,2)=(2,2) $$
유도 1
$$ b=-\tfrac12(\boldsymbol{\mu}_1^\top\boldsymbol{\mu}_1-\boldsymbol{\mu}_0^\top\boldsymbol{\mu}_0)+\log1=-\tfrac12(8-0)=-4 $$
$\boldsymbol{\mu}_1^\top\boldsymbol{\mu}_1=4+4=8$
$$ \text{경계}:\ 2x_1+2x_2-4=0 \ \Rightarrow\ x_1+x_2=2 $$
두 중심의 수직이등분선 — 대칭이니 당연하다 ✓
$$ \mathbf{x}=(1.5,\ 1):\ \mathbf{w}^\top\mathbf{x}+b=3+2-4=1 \ \Rightarrow\ \sigma(1)=0.7311 $$
class 1 쪽. 정확히 sigmoid 로 나온다
$$ \pi_1=0.8 \text{ 이었다면}:\ b=-4+\log\tfrac{0.8}{0.2}=-4+1.3863=-2.6137 $$
사전확률이 경계를 평행이동시킨다
$$ \text{경계}:\ 2x_1+2x_2=2.6137 \ \Rightarrow\ x_1+x_2=1.307 $$
흔한 class 쪽으로 경계가 밀려난다

③ EM 한 라운드를 손으로 — 1차원 GMM

data $x=(1,\ 2,\ 8,\ 9)$. 두 봉우리, 초기값 $\mu_1=2,\ \mu_2=7,\ \sigma_1=\sigma_2=2,\ \pi_1=\pi_2=0.5$.

$$ \mathcal{N}(x\mid\mu,2)\propto\exp\Bigl(-\frac{(x-\mu)^2}{8}\Bigr) $$
$\sigma=2$ 라 $2\sigma^2=8$. $\pi$ 와 정규화 상수가 같으니 지수부만 비교하면 된다
$$ x=1:\ e^{-1/8}=0.8825,\quad e^{-36/8}=e^{-4.5}=0.01111 $$
$(1-2)^2=1$, $(1-7)^2=36$
$$ \gamma_{11}=\frac{0.8825}{0.8825+0.01111}=0.9876,\qquad \gamma_{12}=0.0124 $$
E-step, 식 (7)
$$ x=2:\ e^{0}=1,\ e^{-25/8}=0.04394 \ \Rightarrow\ \gamma_{21}=0.9579,\ \gamma_{22}=0.0421 $$
$(2-7)^2=25$
$$ x=8:\ e^{-36/8}=0.01111,\ e^{-1/8}=0.8825 \ \Rightarrow\ \gamma_{31}=0.0124,\ \gamma_{32}=0.9876 $$
$x=1$ 과 대칭
$$ x=9:\ e^{-49/8}=0.002187,\ e^{-4/8}=0.6065 \ \Rightarrow\ \gamma_{41}=0.003593,\ \gamma_{42}=0.9964 $$
$(9-2)^2=49$, $(9-7)^2=4$
$$ N_1=0.9876+0.9579+0.0124+0.003593=1.9615 $$
유효 표본 수 — 정수가 아니다
$$ \mu_1^{\text{new}}=\frac{0.9876(1)+0.9579(2)+0.0124(8)+0.003593(9)}{1.9615} $$
M-step, 식 (7)
$$ =\frac{0.9876+1.9158+0.0992+0.03234}{1.9615}=\frac{3.0349}{1.9615}=1.5473 $$
$2 \to 1.547$ — 왼쪽 두 점 쪽으로 끌려갔다
$$ N_2=4-1.9615=2.0385,\qquad \pi_1^{\text{new}}=\frac{1.9615}{4}=0.4904 $$
$\sum_k\gamma_{ik}=1$ 이므로 $N_1+N_2=n$ ✓
$$ \mu_2^{\text{new}}=\frac{0.0124(1)+0.0421(2)+0.9876(8)+0.9964(9)}{2.0385}=\frac{16.965}{2.0385}=8.322 $$
$7\to8.32$ — 오른쪽 두 점의 평균 8.5 쪽으로. 몇 번 더 돌면 1.5 와 8.5 로 수렴한다

④ HMM — Viterbi 를 손으로

상태 {맑음 S, 비 R}. 초기 $p(S)=0.6,\ p(R)=0.4$. 전이 $A_{SS}=0.7,\ A_{SR}=0.3,\ A_{RS}=0.4,\ A_{RR}=0.6$. 방출 $p(\text{우산}\mid S)=0.1,\ p(\text{우산}\mid R)=0.8$. 관측: 우산, 우산.

$$ \delta_1(S)=0.6\times0.1=0.06,\qquad \delta_1(R)=0.4\times0.8=0.32 $$
$t=1$: 초기확률 × 방출확률
$$ \delta_2(S)=\max(0.06\times0.7,\ 0.32\times0.4)\times0.1 $$
$t=2$ 에 S 로 가는 두 경로 중 더 좋은 것만 남긴다
$$ =\max(0.042,\ 0.128)\times0.1=0.128\times0.1=0.0128 \quad(\text{앞이 } R) $$
역추적용으로 "앞은 R" 을 기록
$$ \delta_2(R)=\max(0.06\times0.3,\ 0.32\times0.6)\times0.8=\max(0.018,\ 0.192)\times0.8 $$
$$ =0.192\times0.8=0.1536 \quad(\text{앞이 } R) $$
$$ \max(0.0128,\ 0.1536)=0.1536 \ \Rightarrow\ z_2=R,\ \text{역추적하면 } z_1=R $$
최적 상태열 = (비, 비). 우산을 이틀 들었으니 당연하다 ✓
$$ \text{경로가 } K^T=2^2=4 \text{ 개인데 } \delta \text{ 는 매 시점 } K=2 \text{ 개만 유지} $$
$T=100$ 이면 $2^{100}$ 대신 200번의 계산 — 동적계획법의 위력

흔한 오해와 함정

오해 1

"naive Bayes 의 predict_proba 값을 확률로 믿어도 된다."

실제로는 거의 언제나 0 또는 1 에 붙어 있다. 상관된 feature 를 독립인 척 곱하면 같은 증거를 여러 번 세는 셈이라 확신이 지수적으로 부풀기 때문이다. 그런데도 argmax 는 자주 맞아 분류 정확도는 괜찮다(접힌 상자). 순위는 쓰되 확률값은 쓰지 말라는 것이 실무 규칙이며, 정말 필요하면 4.9의 보정을 별도로 붙여야 한다.

오해 2

"EM 은 최대우도해를 찾아 준다."

실제로는 국소 최대로 갈 뿐이다. 유도 2 가 보장하는 것은 "우도가 줄지 않는다"이지 "전역 최대에 도달한다"가 아니다. GMM 의 우도 지형은 봉우리가 여러 개이고, 게다가 label 바꿔치기 대칭($K!$ 가지)까지 있다. 처방은 여러 초기값에서 돌려 가장 좋은 것을 고르는 것(n_init=10)이고, k-means 결과로 초기화하면 훨씬 안정적이다.

오해 3

"GMM 은 봉우리 수 $K$ 를 우도로 고르면 된다."

실제로는 $K$ 를 늘리면 우도는 반드시 올라간다 — 5.6에서 트리를 깊게 하면 train 오차가 줄던 것과 같은 이야기다. 극단적으로 $K=n$ 이면 각 점에 봉우리를 하나씩 두고 분산을 0 으로 보내 우도를 무한대로 만들 수 있다(특이해). 그래서 BIC·AIC 처럼 복잡도에 벌점을 주는 기준이나 교차검증으로 골라야 하고, reg_covar 로 공분산에 하한을 주어 특이해를 막는다.

오해 4

"QDA 가 LDA 보다 유연하니 언제나 더 좋다."

실제로는 parameter 가 $K$배로 늘어난다. $d$=50, $K$=3 이면 LDA 1,425 개 vs QDA 4,005 개 — class 당 표본이 $d$ 보다 적으면 공분산 행렬이 특이해져 역행렬조차 없다. $n$ 이 크고 $d$ 가 작으며 class 별 산포가 뚜렷이 다를 때만 QDA 가 이긴다. 중간을 원하면 정규화 판별분석($\boldsymbol{\Sigma}_c$ 를 공유 $\boldsymbol{\Sigma}$ 쪽으로 축소)을 쓴다.

오해 5

"생성 model 은 판별 model 보다 원리적으로 우수하다 — 분포 자체를 배우니까."

실제로는 더 어려운 문제를 푸는 것이고, 그 대가가 있다. 분류만 필요한데 $p(\mathbf{x}\mid y)$ 전체를 추정하는 것은 필요 이상의 일이며, 그 가정이 틀리면 표본을 아무리 늘려도 오차가 안 줄어든다. 반대로 표본이 적을 때는 가정이 정보를 보태 생성 model 이 앞선다 — 즉 $n$ 이 작으면 생성, 크면 판별이라는 교차점이 존재하며, 이는 이론과 실험으로 확인된 결과다2.

NumPy — naive Bayes · EM 한 라운드 · Viterbi (22줄) 
import numpy as np

ps, pn = 0.6, 0.4                                        # 예제 ①
p_free = (6/8, 2/6); p_meet = (2/8, 4/6)
s = ps * p_free[0] * (1 - p_meet[0]); n = pn * p_free[1] * (1 - p_meet[1])
print(round(s, 5), round(n, 5), round(s / (s + n), 4))   # 0.3375 0.04444 0.8836

x = np.array([1., 2, 8, 9]); mu = np.array([2., 7]); sd = 2.0   # 예제 ③
d = np.exp(-(x[:, None] - mu)**2 / (2 * sd**2))
g = d / d.sum(1, keepdims=True)
N = g.sum(0)
print(np.round(g, 4)); print(np.round(N, 4), np.round(g.T @ x / N, 4))
# N = [1.9615 2.0385],  새 mu = [1.5473 8.3222]

A = np.array([[.7, .3], [.4, .6]]); B = np.array([.1, .8]); pi0 = np.array([.6, .4])
d1 = pi0 * B                                             # 예제 ④
d2 = np.array([(d1 * A[:, k]).max() * B[k] for k in range(2)])
bp = np.array([(d1 * A[:, k]).argmax() for k in range(2)])
print(np.round(d1, 4), np.round(d2, 4), bp)              # [0.06 0.32] [0.0128 0.1536] [1 1]
z2 = d2.argmax(); print('최적 상태열:', bp[z2], z2)       # 1 1 = (비, 비)

두 번째 블록의 $N_1+N_2=4$ 는 책임도의 행 합이 1 이라는 성질에서 나온다. 새 $\mu$ 가 $(1.547,\ 8.322)$ 로 예제 ③과 일치하고, 초기값 $(2,7)$ 보다 참 중심 $(1.5,\ 8.5)$ 에 가까워졌다.

계산 어떤 단어가 스팸 3통 / 전체 스팸 7통에 나왔다. $\alpha=1$ Laplace 평활한 확률은?

풀이 · Bernoulli 는 값이 있음/없음 두 가지라 $V=2$ → $\frac{3+1}{7+1\times2}=\frac49=0.444$ (식 3). 나는 평활 없는 값, 다는 분모에 $\alpha V$ 대신 $\alpha$ 만 더한 것이다. 분모에도 반드시 $\alpha V$ 를 더해야 확률의 합이 1 이 된다.

계산 $\boldsymbol{\mu}_0=(0,0)$, $\boldsymbol{\mu}_1=(4,0)$, $\boldsymbol{\Sigma}=\mathbf{I}$, $\pi_0=\pi_1$ 일 때 LDA 경계는?

풀이 · $\mathbf{w}=(4,0)$, $b=-\frac12(16-0)=-8$ → $4x_1-8=0$ → $x_1=2$ (유도 1). 두 중심의 수직이등분선이다. $\pi_1$ 을 키우면 이 선이 class 0 쪽으로 밀린다 — 흔한 class 의 영역이 넓어진다.

계산 어떤 점의 책임도가 $\gamma=(0.7,\ 0.3)$ 이다. 이 점이 M-step 에서 하는 일은?

풀이 · 식 (7)의 $\boldsymbol{\mu}_k=\sum_i\gamma_{ik}\mathbf{x}_i/\sum_i\gamma_{ik}$ 는 책임도로 가중한 평균이다 — 한 점이 여러 봉우리에 쪼개져 들어간다. 나가 바로 k-means 의 딱딱한 배정이고, GMM 은 그 부드러운 판이라 겹친 무리를 다룰 수 있다.

개념 EM 을 돌렸더니 로그우도가 한 번 내려갔다. 무엇을 의심해야 하나?

풀이 · 유도 2 가 $\log p(X\mid\theta^{(t+1)})\ge\log p(X\mid\theta^{(t)})$ 를 보장한다 — 수치오차 수준이 아니라 눈에 띄게 내려갔다면 거의 확실히 버그다. 흔한 원인은 E-step 의 정규화 누락, 공분산 갱신에 옛 $\mu$ 대신 새 $\mu$ 를 안 쓴 것, 로그우도를 정규화 상수 없이 계산한 것이다. 이 단조성은 구현 검증에 쓸 수 있는 가장 좋은 불변식이다.

개념 표본이 아주 적을 때 생성 model 이 판별 model 보다 유리한 이유는?

풀이 · "각 class 가 정규분포"라는 가정은 data 로 채워야 할 자유도를 미리 줄인다 — 5.2의 편향-분산에서 편향을 늘리고 분산을 줄이는 쪽이다. $n$ 이 커지면 분산이 저절로 줄어 편향만 남으므로 판별 model 이 앞선다 — 둘 사이에 교차점이 있다(오해 5).

함정 GMM 을 학습했더니 한 봉우리의 분산이 0 으로 가고 우도가 발산했다. 원인은?

풀이 · 봉우리 하나가 표본 한 점에 정확히 올라앉으면 $\sigma\to0$ 일 때 그 점의 밀도가 무한대로 가 우도가 발산한다(오해 3). GMM 의 우도는 위로 유계가 아니므로 "최대우도해"가 잘 정의되지 않는 것이다. 처방은 공분산에 $\epsilon\mathbf{I}$ 를 더하는 것(reg_covar), 또는 사전분포를 두어 MAP 추정으로 바꾸는 것이다.
